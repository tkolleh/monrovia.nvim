TEMPLATES                                               *monrovia-templates*

Templates allow referencing of other lower level objects in monrovia's
config. Instead of setting an absolute color value, you can refer to a
lower object's value instead. The base of monrovia is a |monrovia-palette|.
A palette does not use a template as it is the base that others build off
of. |monrovia-palette| values are used as the template source for
|monrovia-spec| objects. |monrovia-spec| objects are used as the template
source for |monrovia-group| objects.

If a value does not start with the `#` symbol it will be treated as a
template path. A template `path` is the keys used to index into the table,
separated by `.` characters.

Note: If the resulting value of a template is a |monrovia-shade| then the
`base` value will be used.

Example: >lua
  local specs = {
    monrovia_night = {
      syntax = {
        -- Value does not start with `#` so is treated as a template.
        -- Since `magenta` is a `shade` object the `base` value will be used.
        keyword = "magenta",

        -- Adding either `.bright` or `.dim` will change the value
        conditional = "magenta.bright",
        number = "orange.dim",
      },
    },
  }

  local groups = {
    all = {
      -- The template path is parsed to [`syntax`, `string`]. This is like
      -- calling into a lua table: `spec.syntax.string`.
      String = { fg = "syntax.string" },
    },
  }

  require('monrovia').setup({ specs = specs, groups = groups })
<

OPTION                                                     *monrovia-option*

                                              *monrovia-options.compile_path*
options.compile_path ~
    The output directory where the compiled results will be written to.
    Default: `vim.fn.stdpath("cache")/monrovia`.

                                        *monrovia-options.compile_file_suffix*
options.compile_file_suffix ~
    The string appended to the compiled file. Each `style` outputs to its
    own file, with this suffix appended to the end of the file name.
    Default: `_compiled`

                                               *monrovia-options.transparent*
options.transparent ~
    A boolean value that if set disables setting the background of
    `Normal`, `NormalNC` and other highlight groups. This lets you use the
    colors of the colorscheme but keep the background of your terminal.
    Default: `false`.

                                            *monrovia-options.terminal_colors*
options.terminal_colors ~
    A boolean value that if set defines the terminal colors for the
    builtin `:terminal` (`vim.g.terminal_color_*`). Default: `true`.

                                              *monrovia-options.dim_inactive*
options.dim_inactive ~
    A boolean value that if set darkens the background of non-current
    windows. See |hl-NormalNC|.

                                            *monrovia-options.module_default*
options.module_default ~
    The default enabled value for a module that has not been overridden in
    the `modules` table.

                                                    *monrovia-options.styles*
options.styles ~
    A table of syntax components and their corresponding style. Values can
    be any combination of |attr-list|. The syntax components are: >
      comments, conditionals, constants, functions, keywords, numbers,
      operators, preprocs, strings, types, variables
<
    Example: >lua
      local options = {
        styles = {
          comments = "italic",
          functions = "italic,bold",
        }
      }
<
                                                   *monrovia-options.inverse*
options.inverse ~
    A table of highlight types that, when enabled, inverse the foreground
    and background colors instead of applying the normal highlight group.
    The highlight types are: `match_paren`, `visual`, `search`.

                                                *monrovia-options.colorblind*
options.colorblind ~
    Configuration for monrovia's color vision deficiency (cvd) mode. See
    the readme's Colorblind section for how this works. Shape: >lua
      colorblind = {
        enable = false,        -- Enable colorblind support
        simulate_only = false, -- Only show simulated colors, not diff shifted
        severity = {
          protan = 0,          -- Severity [0,1] for protan (red)
          deutan = 0,          -- Severity [0,1] for deutan (green)
          tritan = 0,          -- Severity [0,1] for tritan (blue)
        },
      }
<
                                                  *monrovia-options.modules*
options.modules ~
    Configuration for various plugins and other neovim modules. A module
    value is either a `boolean` or a table with additional configuration
    for that module. A table value has a field called `enable` that tells
    monrovia whether to load it. See |monrovia-modules|.

    By default modules are enabled; change this with `options.module_default`.

SHADE                                                       *monrovia-shade*

A `shade` groups a `base` color with a `bright` and `dim` version. This is
the base struct that palette colors are defined from. Example: >lua
  local Shade = require("monrovia.lib.shade")
  local red = Shade.new("#bf616a", "#d06f79", "#a54e56")
  print(vim.inspect(red))
  -- {
  --   base = "#bf616a",
  --   bright = "#d06f79",
  --   dim = "#a54e56",
  -- }
<
This is a convenience structure used internally to build a palette and
should not be used outside of it. It is documented here to help understand
the structure of a |monrovia-palette|.

==============================================================================
PALETTE                                                   *monrovia-palette*

A `palette` is the base color definitions of a style. Each style defines
its own palette. A palette defines base colors as well as foreground and
background shades, plus selection and comment colors.

The base colors are |monrovia-shade| objects (`base`, `bright`, `dim`):
`black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`,
`orange`, `pink`.

    Key       Description ~
    comment   Comment color
    bg0       Darker bg (status line and float)
    bg1       Default bg
    bg2       Lighter bg (colorcolumn, folds)
    bg3       Lighter bg (cursor line)
    bg4       Lighter bg (conceal, border fg)
    fg0       Lighter fg
    fg1       Default fg
    fg2       Darker fg (status line)
    fg3       Darker fg (line numbers, fold columns)
    sel0      Popup bg, visual selection bg
    sel1      Popup sel bg, search bg

SPEC                                                         *monrovia-spec*

A `spec` (specification) maps palette values to a logical group used by
|monrovia-group|. The base of a spec re-exports the palette's `bg` and `fg`
shades plus `sel`: `bg0`, `bg1`, `bg2`, `bg3`, `bg4`, `fg0`, `fg1`, `fg2`,
`fg3`, `sel0`, `sel1`.

                                                       *monrovia-spec.syntax*
spec.syntax ~
    Maps palette color values to syntax values used by |monrovia-group|.

    Key           Description ~
    bracket       Brackets and punctuation
    builtin0      Builtin variable
    builtin1      Builtin type
    builtin2      Builtin const
    comment       Comment
    conditional   Conditional and loop
    const         Constants, imports and booleans
    dep           Deprecated
    field         Field
    func          Functions and titles
    ident         Identifiers
    keyword       Keywords
    number        Numbers
    operator      Operators
    preproc       PreProc
    regex         Regex
    statement     Statements
    string        Strings
    type          Types
    variable      Variables

                                                      *monrovia-spec.diag*
spec.diag ~
    Maps palette colors to `vim.diagnostic` colors: `error`, `warn`,
    `info`, `hint`, `ok`.

                                                   *monrovia-spec.diag_bg*
spec.diag_bg ~
    Maps palette colors to `vim.diagnostic` background colors: `error`,
    `warn`, `info`, `hint`, `ok`.

                                                      *monrovia-spec.diff*
spec.diff ~
    Maps palette colors to vimdiff highlight colors: `add`, `delete`,
    `change`, `text`.

                                                       *monrovia-spec.git*
spec.git ~
    Maps palette colors to git colors: `add`, `removed`, `changed`,
    `conflict`, `ignored`.

==============================================================================
GROUP                                                       *monrovia-group*

A `group` is the definition of a highlight group. The table key is the
highlight-group name to define; the value is the arguments to |:highlight|.

    Key     Help              Description ~
    fg      |highlight-guifg| Foreground color
    bg      |highlight-guibg| Background color
    sp      |highlight-guisp| Color for underlines and undercurls
    style   |highlight-gui|   Style, e.g. `italic`, `bold`
    link    |highlight-link|  Link one highlight group to another

If `link` is present and not empty, monrovia links the group to the
corresponding value instead of applying the other fields.

MODULES                                                   *monrovia-modules*

Modules add highlight support for plugins and neovim features, and can be
individually enabled or disabled. A `base` module is just a `boolean`. An
`extended` module is a table with additional configuration plus an
`enable` field.

The current list of modules is kept in code at `lua/monrovia/config.lua`'s
`module_names`
(https://github.com/tkolleh/monrovia.nvim/blob/main/lua/monrovia/config.lua)
to avoid drifting out of sync with this doc. See the readme's Supported
Plugins section for the equivalent list with links to each plugin.

`diagnostic`, `native_lsp`, and `treesitter` are enabled by default only on
neovim, and remain enabled even when `module_default` is `false`, since
other modules link to them.

                                                     *monrovia-modules.coc*
modules.coc ~
    Sets highlight groups for `neoclide/coc.nvim`.

    key          type      default   description ~
    enable       boolean   true      Enable the module
    background   boolean   true      Set virtual text background color

                                              *monrovia-modules.diagnostic*
modules.diagnostic ~
    Sets highlight groups for `vim.diagnostic`.

    key          type      default   description ~
    enable       boolean   true      Enable the module
    background   boolean   true      Set virtual text background color

                                              *monrovia-modules.native_lsp*
modules.native_lsp ~
    Sets highlight groups for neovim's builtin `lsp`.

    key          type      default   description ~
    enable       boolean   true      Enable the module
    background   boolean   true      Set virtual text background color

                                                    *monrovia-modules.leap*
modules.leap ~
    key          type      default   description ~
    enable       boolean   true      Enable the module
    background   boolean   true      Set the label color to the background
    harsh        boolean   false     Make the label's contrast harsher

COLOR                                                       *monrovia-color*

Monrovia exposes a color utility library: >lua
  local Color = require('monrovia.lib.color')
<
                                                *monrovia-color.from_hex()*
color.from_hex({hex}) ~
    Create a `Color` from either a {hex} number or a css-style hex string
    (`"#RRGGBB[AA]"`).

                                               *monrovia-color.from_rgba()*
color.from_rgba({red}, {green}, {blue}, {alpha}) ~
    Create a `Color` from an RGBA value. {red}, {green}, {blue} range
    `[0,255]`. {alpha} is optional, defaults to `1`, and ranges `[0,1]`.

                                                *monrovia-color.from_hsv()*
color.from_hsv({hue}, {sat}, {value}, {alpha}) ~
    Create a `Color` from an HSV value. {hue} is a float ranging `[0,360]`.
    {sat} and {value} range `[0,100]`. {alpha} is optional, defaults to
    `1`, and ranges `[0,1]`.

                                                *monrovia-color.from_hsl()*
color.from_hsl({hue}, {sat}, {lightness}, {alpha}) ~
    Create a `Color` from an HSL value. {hue} is a float ranging `[0,360]`.
    {sat} and {lightness} range `[0,100]`. {alpha} is optional, defaults to
    `1`, and ranges `[0,1]`.

                                                  *monrovia-color:to_hex()*
color:to_hex({with_alpha}) ~
    Convert to an integer. If {with_alpha} is true the alpha value is
    included. Defaults to `false`.

                                                  *monrovia-color:to_css()*
color:to_css({with_alpha}) ~
    Convert to a css-style string (`"#RRGGBB[AA]"`). If {with_alpha} is
    true the alpha value is included. Defaults to `false`.

                                                 *monrovia-color:to_rgba()*
color:to_rgba() ~
    Convert to an RGBA table with `red`, `green`, `blue`, `alpha` keys.

                                                  *monrovia-color:to_hsv()*
color:to_hsv() ~
    Convert to an HSV table with `hue`, `saturation`, `value` keys.

                                                  *monrovia-color:to_hsl()*
color:to_hsl() ~
    Convert to an HSL table with `hue`, `saturation`, `lightness` keys.

                                                  *monrovia-color:blend()*
color:blend({other}, {factor}) ~
    Return a new `Color` linearly blended with {other}. {factor} ranges
    `[0,1]`, where `0` is entirely the original color and `1` is entirely
    {other}.

                                                  *monrovia-color:shade()*
color:shade({factor}) ~
    Return a new `Color` shaded by {factor}, ranging `[-1,1]` where `-1` is
    black and `1` is white.

                                               *monrovia-color:brighten()*
color:brighten({value}) ~
    Return a new `Color` with {value} added to its HSV `value`. {value} is
    a float in `[-100,100]`; positive lightens, negative darkens.

                                                *monrovia-color:lighten()*
color:lighten({value}) ~
    Return a new `Color` with {value} added to its HSL `lightness`.
    {value} is a float in `[-100,100]`; positive lightens, negative
    darkens.

                                               *monrovia-color:saturate()*
color:saturate({value}) ~
    Return a new `Color` with {value} added to its HSV `saturation`.
    {value} is a float in `[-100,100]`.

                                                 *monrovia-color:rotate()*
color:rotate({value}) ~
    Return a new `Color` with {value} added to its HSV `hue`. {value} is a
    float in `[-100,100]`; the resulting hue wraps within `[0,360]`.
